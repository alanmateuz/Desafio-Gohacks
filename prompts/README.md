# prompts/

Prompts que funcionaram, com versão: `<nome>_v1.md`, `<nome>_v2.md`…
Nunca sobrescreva uma versão: crie a próxima e anote no `projeto/decisoes.md` o que mudou e por quê
(ex.: "v2 adiciona exemplos de claim implícito; taxa 70% → 90%").

`classificar_v1.md` é só um exemplo de formato: JSON com schema, regra de dúvida e defesa contra instrução no texto.
