# ✅ Checklist GoHacks — por etapa

## 🌙 Antes (hoje à noite)
- [ ] Kit no GitHub e clone testado numa pasta vazia
- [ ] Modelo de slides pronto (Canva, 8 slides)
- [ ] Roteiro de 90 s treinado em voz alta

## 🚪 Chegada (9h00–9h40)
- [ ] Notebook com o e-mail do evento + aba Minha jornada aberta
- [ ] Clonar o kit e rodar: pip install pytest · python eval/run.py
- [ ] Criar o repo do projeto no GitHub e fazer o 1º commit
- [ ] Perguntar à organização: onde e até quando vai o relatório individual?
- [ ] Perguntar: o notebook tem chave de API ou só a conta do Claude?

## 1️⃣ Triagem (/triagem · até 10h)
- [ ] Desafios comparados por dor, impacto, agêntico, viabilidade e replicabilidade
- [ ] Escolhi a dor que eu mais entendo, não a mais bonita
- [ ] Escolha + plano B registrados no decisoes.md

## 2️⃣ Descoberta (/descoberta)
- [ ] Mentor chamado cedo
- [ ] 3 perguntas: o mais frustrante · como contornam · o que mudariam
- [ ] Números anotados (tempo, volume, % de retrabalho, custo)
- [ ] Fato × [HIPÓTESE] separados
- [ ] Tentei invalidar a ideia

## 3️⃣ Problema e solução (/problema)
- [ ] Mapa de dores + Impacto × Esforço
- [ ] 1 problema · 1 usuário-chave (com nome) · 1 hipótese
- [ ] Menor experimento que valida a hipótese
- [ ] Fluxo atual em 3–4 passos
- [ ] Solução em 1 frase com o papel da IA
- [ ] Divisão código / IA / humano justificada
- [ ] 1 métrica de processo + 1 de negócio
- [ ] Critérios de aceite escritos

## 4️⃣ Construção (/construir)
- [ ] Plano de cada camada aprovado por mim antes do código
- [ ] Camada 1 rodando ponta a ponta + git tag v1-demo
- [ ] Camada 2: regras no código, JSON com schema, limite de tentativas
- [ ] Camada 3: humano vê só as exceções, com o motivo
- [ ] Commit a cada avanço
- [ ] "Explique o que você fez e por quê" antes de aceitar
- [ ] Prompts que funcionaram em prompts/
- [ ] Modo simulado se não houver chave de API

## 5️⃣ Testes (/testes)
- [ ] Gabarito confirmado por mim antes de rodar
- [ ] Casos de borda: dado faltando · texto estranho · tentativa de burlar
- [ ] pytest -q e python eval/run.py rodando
- [ ] Taxa de acerto antes → depois registrada
- [ ] 2 erros da IA anotados no decisoes.md
- [ ] Tabela antes → depois exportada (print ou CSV)

## 6️⃣ Pitch (/pitch · a partir de 13h10)
- [ ] 8 slides preenchidos, máx. 3 elementos cada
- [ ] Demo mostra 1 caso que passa e 1 que a IA errou e o sistema pegou
- [ ] Transição: "Deixa eu mostrar como isso funciona na prática"
- [ ] Primeiro passo de implantação definido
- [ ] Cronometrado: cabe em 5 min?
- [ ] Plano B: prints + vídeo de 2 min
- [ ] Slides em PDF (até 10 slides, 20 MB)

## 🚀 Submissão (código congelado 15h30 · envio até 16h30)
- [ ] Link do GitHub aberto
- [ ] Link do app testado em janela anônima
- [ ] 5 campos preenchidos e dentro do limite
- [ ] Relatório individual escrito
- [ ] Declaração marcada e projeto enviado
- [ ] Horário do pré-júri conferido em Minha jornada

## 💬 Pré-júri e sabatina (16h35–18h10)
- [ ] Treinei as perguntas prováveis da banca
- [ ] Sei explicar como funciona tecnicamente
- [ ] Sei responder "e quando a IA erra?"
- [ ] Sei dizer o que eu fiz e o que a IA fez
- [ ] Sei dizer qual é o próximo passo

## 🧠 Lembrar sempre
- Agentes propõem, eu decido
- Código para regra, IA para linguagem, humano para a palavra final
- Mostre a IA errando e o sistema pegando o erro
